# Projet : OO Systems Development


## Récupérer une clé api sur le site OMDB 
**Le lien** : https://www.omdbapi.com/apikey.aspx

Ajouter le `.env` à la racine du projet :

```
API_KEY_OMDB=Votre_clé
```

## Stack

- **Frontend** : React (Vite), React Router

## Lancer le projet

### Frontend

```
npm install
npm run dev
```

Client disponible sur `http://localhost:5173`
